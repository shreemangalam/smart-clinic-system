# Smart Clinic Management System - User Stories

## Admin
* **As an Admin**, I want to add, update, and remove doctors from the system so that the clinic's staff directory remains accurate.
* **As an Admin**, I want to view daily appointment reports so that I can monitor clinic operations and load.

## Doctor
* **As a Doctor**, I want to view my upcoming appointments for the day so that I can manage my schedule.
* **As a Doctor**, I want to add prescription records for my patients after an appointment so that their medical history is tracked.

## Patient
* **As a Patient**, I want to search for doctors by specialty and view their available time slots so that I can find the right physician.
* **As a Patient**, I want to book an appointment with a specific doctor so that I can receive medical consultation.
